💰 MoneyTax – Simulador de Vida Financeira
MoneyTax é um jogo educacional desenvolvido na Unity com foco em simular a vida financeira de um trabalhador, abordando conceitos como salário, impostos, despesas e planejamento financeiro.
🎯 Objetivo
O objetivo do projeto é ensinar, de forma interativa, como funciona a gestão financeira no dia a dia, incluindo crescimento profissional, tomada de decisões e organização de gastos.
⚙️ Funcionalidades
📅 Sistema de tempo (dias, meses e anos)
💼 Progressão de carreira (estagiário → cargos maiores)
💰 Cálculo de salário com descontos (INSS, IRPF, transporte)
🎮 Minigame mensal obrigatório para receber salário
🎓 Sistema de cursos (ex: Office, MBA)
⚠️ Eventos aleatórios (ex: doença, imprevistos)
🏠 Sistema de compras (casa, carro, etc.)
📊 Planejamento financeiro (controle de gastos e reserva)
🛠️ Tecnologias utilizadas
C#
Unity
PlayerPrefs (persistência de dados)
🧠 Aprendizados
Durante o desenvolvimento deste projeto, foram aplicados conceitos como:
Lógica de programação
Estruturação de sistemas complexos
Organização de código em C#
Criação de mecânicas de jogo
Persistência de dados
Desenvolvimento de interfaces e interação com o usuário
🚀 Status do projeto
Projeto funcional, com sistemas principais implementados e possibilidade de futuras melhorias e expansão.
📌 Observações
Este projeto foi desenvolvido de forma individual como parte da minha formação em programação de jogos digitais.
